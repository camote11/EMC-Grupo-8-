# Disney Plus Simulador

## Descripción del proyecto

Este proyecto tiene como objetivo desarrollar un simulador de Disney Plus mediante Python. El repositorio organiza el código fuente, la documentación y los registros de pruebas para facilitar el desarrollo, la ejecución y la evaluación del proyecto.

## Objetivos

- Desarrollar la lógica del simulador de manera modular.
- Organizar la planificación y los modelos del sistema.
- Registrar las pruebas realizadas y documentar los resultados.
- Mantener una estructura de código clara y fácil de mantener.

## Estructura del repositorio

```text
grupo-8/
├── .gitignore
├── README.md
├── docs/
│   └── informe.md
├── capturas/
│   └── ejecucion_prueba.txt
└── src/
    ├── plan.py
    ├── models.py
    └── main.py
```

## Tecnologías

- Python 3
- Git
- GitHub

## Organización del código

- **`src/plan.py`:** módulo destinado a la planificación del simulador.
- **`src/models.py`:** módulo destinado a definir los modelos y las clases del sistema.
- **`src/main.py`:** punto de entrada para ejecutar el programa.
- **`docs/informe.md`:** documentación e informe del proyecto.
- **`capturas/ejecucion_prueba.txt`:** registro de ejecución y pruebas.

## Estado del proyecto

**En desarrollo.** La estructura inicial del repositorio está establecida. La implementación de la lógica, las pruebas y la documentación detallada se completarán progresivamente.

## Ejecución

Una vez implementado el código, el programa podrá ejecutarse desde la carpeta `src` mediante:

```bash
python main.py
```

Los requisitos adicionales y las instrucciones definitivas de ejecución se incorporarán conforme avance el desarrollo.
